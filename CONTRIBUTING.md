# Contributing to Awesome Physical AI

We welcome contributions from researchers, roboticists, and engineers!

## Contribution Guidelines:
1. **Verifiability:** Ensure all cited papers include valid arXiv or conference publication links.
2. **Taxonomy Alignment:** Place models and papers in their correct architectural cluster.
3. **No Decorative Fluff:** Keep summaries crisp, mathematically precise, and focused on reproducible results.

To submit a contribution:
1. Fork the repository.
2. Create your feature branch (git checkout -b feature/add-model-name).
3. Commit your changes (git commit -m 'Add SOTA VLA paper').
4. Push to the branch (git push origin feature/add-model-name).
5. Open a Pull Request.
